# Simulation data for the reported experiments

Repository: https://github.com/me2ulab/event-urgency-dodge. Everything below was generated by the code in this
repository and can be regenerated with `./run_all.sh` (about 5 min). Both simulators are deterministic, so a
rerun reproduces these files exactly. `results/REPORT.md` lists every regenerated value alongside the value
reported in the paper; a few differ (e.g. the Gazebo dodge time, 3.85 s regenerated against 3.72 s reported).

## File formats (each experiment folder)

| File | Content |
|---|---|
| `summary.json` | One run's outcome: commit time and diameter, τ̂ and true τ at commit, minimum separation (continuous and per-tick), collision flag, goal time, speeds |
| `params.json` | Every parameter of the run (camera, event model, detector, tracker, gate, controller, encounter, corridor) |
| `log.npz` | One row per 25 ms tick. Columns: `t`; UAV `x y z vx vy vz`; ball `bx by bz`; `n_ev` (events this tick); `n_roi`, `n_comp`; detection `det_d det_cu det_cv`; `track looming ddot tau closing gate H committed phase tau_cmd`; `sep` (centre-to-centre, m); timing `t_perc_ms t_cmd_ms`. Load with `numpy.load(...)` |
| `snap_<t>.npz` | At t = 1.35, 3.60, 3.75, 3.90 s: `image` (160×120 uint8 frame), `counts` (events per pixel in the 50 ms window), `polarity` (net ON−OFF per pixel) |
| `snapshots.json` | At the same times: UAV and ball poses, every detected component and the one passed to detection |

Summary across all runs: `results/REPORT.md`, with `results/suite_raytrace.txt` and `results/suite_gazebo.txt`.

## Software

Code to regenerate everything: `urgency_dodge/` (method), `sims/` (ray-traced and Gazebo renderers), `ros2_ws/`
(ROS 2 nodes and RViz), `experiments/` (runner and figures), `tests/`. Software stack: ROS 2 Lyrical, Gazebo
Jetty (gz-sim 10), Python 3.14 with numpy, scipy and matplotlib (see README.md).
